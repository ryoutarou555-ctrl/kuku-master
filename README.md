# ✖ かけ算マスター

**グリッドを埋めて計算力を鍛えよう！**

ランダム配置された9×9グリッドに答えを入力して、九九をマスターする練習Webアプリです。
一問一答ではなく「全部入力してから一括判定」する独自のグリッド方式で、楽しく・効率よく練習できます。

🌐 **[今すぐ遊ぶ](https://あなたのID.github.io/kuku-master/)**

## ✨ 主な機能

### 🐣 キッズモード / 🔥 アドバンスドモード
| | キッズ | アドバンスド |
|---|---|---|
| 対象 | 1〜9の段 | 10〜20の段 |
| グリッド | 9×9（81マス） | 6×6（36マス） |
| 対象年齢 | 小学生 | 中学生〜大人 |

### 🎯 苦手集中練習モード
3回以上プレイすると解放。正解率80%未満の段を自動抽出して集中練習できます。

### 📊 まなびレポート（親用ダッシュボード）
- 段ごとの正解率を自動分析・苦手順に表示
- 正解率の推移グラフ（直近10回）
- 週ごとのプレイ回数グラフ
- AIコーチからの自動アドバイス
- 連続プレイ日数（ストリーク）

### 🏅 バッジコレクション（プレイヤーごと）
| バッジ | 取得条件 |
|---|---|
| 🎯 はじめての全クリア | 全マスを入力して判定 |
| 💯 パーフェクト | 全問正解 |
| ⚡ スピードスター | キッズモードを60秒以内 |
| 🔥 大人のスピードキング | アドバンスドを120秒以内 |
| 🔓 アドバンスドチャレンジャー | アドバンスドモードでプレイ |
| 🌟 3連続正解 | 3問以上連続正解 |
| 👑 コンプリートマスター | 全バッジ取得 |

### 📣 結果シェア機能
ゲーム終了後に結果カード画像を生成。LINE・Instagram・Xなどに直接シェアできます。

### ⌨️ キーボード完全対応
| キー | 動作 |
|---|---|
| `0〜9` | 数字入力 |
| `Enter` | 確定→次のマスへ |
| `Tab / Shift+Tab` | 次/前の未入力マスへ |
| `↑↓←→` | 上下左右のマスへ移動 |
| `Backspace` | 1文字削除 |

## 🚀 使い方

### オンラインで使う
👉 **[かけ算マスターを開く](https://あなたのID.github.io/kuku-master/)**

Safariで開いて「ホーム画面に追加」すると、アプリとして使えます。

### ローカルで動かす
```bash
# リポジトリをクローン
git clone https://github.com/あなたのID/kuku-master.git

# index.html をブラウザで開くだけ
open index.html
```

サーバー不要・インストール不要です。

## 🛠 技術スタック

| 項目 | 内容 |
|---|---|
| フロントエンド | Vanilla HTML / CSS / JavaScript（フレームワークなし） |
| 音声 | Web Audio API（外部ファイル不要） |
| アニメーション | CSS Animation + Canvas API |
